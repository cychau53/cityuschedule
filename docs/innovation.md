\# Innovation



`cityuschedule` is more than a timetable viewer. It combines timetable

validation, clash detection, gap analysis, and calendar export in one

lightweight command-line package.



\## What makes it different



\- \*\*Clash detection:\*\* It identifies overlapping class sessions before a

&#x20; student commits to a timetable.

\- \*\*Gap analysis:\*\* It reports free periods between classes, helping students

&#x20; find time for study, lunch, or travel.

\- \*\*Calendar export:\*\* It creates an `.ics` file that can be imported into

&#x20; common calendar applications.

\- \*\*Simple input:\*\* Students provide a CSV file rather than logging into an

&#x20; external system.

\- \*\*Offline-first design:\*\* The package processes local CSV files and does not

&#x20; require an account, API key, or internet connection.



\## Example use cases



\- Check whether a proposed combination of lecture and tutorial sections

&#x20; overlaps.

\- Find a free gap of at least 45 minutes for lunch or revision.

\- Export a confirmed timetable to Google Calendar, Apple Calendar, or Outlook.

\- Compare two possible timetable combinations before course registration.
